# Service Catalogue

Northgate Digital Ltd (fictional). List prices, per month unless stated.

## Telecoms
- **Hosted VoIP seat (TEL-VOIP):** £12 per user. Includes UK calls, voicemail-to-email and a mobile app.
- **Business FTTP broadband (TEL-FTTP):** £45 per site, up to 900Mb.
- **Leased line 100Mb (TEL-LL):** £350 per site, with a 7-hour fix SLA from the carrier.
- **Business mobile SIM (TEL-MOB):** £18 per SIM with unlimited UK calls and 50GB data.

## Cloud Hosting
- **Cloud virtual server (CLD-VM):** £60 per server (4 vCPU, 16GB RAM), hosted in our Teesside data centre.
- **Cloud backup 1TB (CLD-BKP):** £25 per TB, 30-day retention, copy held off-site.

## Data Centre
- **Colocation 1U (DC-COLO):** £120 per U, with power, cooling and 24/7 access. ISO 27001 certified site.

## Managed IT
- **Managed IT support (MSP-SUP):** £30 per user. Service desk, patching, Microsoft 365 administration and security monitoring.

## Projects and hardware (one-off)
- **Software development (SW-DEV):** quoted per project; typical projects £1,500 to £15,000.
- **Hardware supply (HW-SALE):** laptops, desk phones, firewalls and switches at cost plus margin.
